= schemas.metanorma.org

The canonical host for versioned schema contracts of the Metanorma
ecosampus: https://schemas.metanorma.org.

== How it works

* Schemas are *owned by their product repositories* — this repo only
  serves them. It holds no schema copies.
* `manifest.yml` maps each served path to its source URL. The deploy
  workflow (push, schedule, or manual) pulls each entry verbatim,
  validates it as JSON, publishes to GitHub Pages with the custom
  domain `schemas.metanorma.org`, and generates browsable documentation
  for each schema with
  https://github.com/lutaml/lutaml-jsonschema[lutaml-jsonschema].
* Each entry serves at three places:
** `<path>` — the raw JSON Schema, byte-identical to the source
   (this is the permanent `$id` URL; never change it)
** `<path without .json>/` — a styled documentation SPA generated from
   the schema (navigation, property tables, search)
** the index page links both plus the source repository.
* To publish a new schema: add one manifest entry. Nothing else —
  the raw file, the documentation page and the index entry are all
  generated from it.

== Stability

Schema `$id` values under this host are permanent identifiers.
Within a major version, changes are additive only.

== Custom domain

`schemas.metanorma.org` is a CNAME to `metanorma.github.io`
(GoDaddy DNS). HTTPS is enforced once the certificate is provisioned.
